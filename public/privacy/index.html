Website privacy

Your privacy matters.

This notice covers the public Yutaka website, not the installed Yutaka app or independently deployed sync Workers. Review and adapt this notice for your jurisdiction before launching publicly.

Static app previews

The screenshots and financial illustrations on this website use fictional records. They are static images and illustrations. This website does not collect finance entries or connect to your private app data.

External links and fonts

Download files are hosted by GitHub. Opening the download chooser checks GitHub's public release API for updated download links. GitHub receives the browser's request; its privacy policy applies. Optional store links take you to Google Play or Microsoft Store when configured. This website also loads a typeface from Google Fonts, which receives the browser's request for the font files.

Hosting and security

The website runs on Cloudflare Workers Static Assets and has no website database or release-notification signup. The hosting provider may process standard network and security logs. No tracking or advertising SDK is included in this website template.
